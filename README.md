中国热门旅游城市气候格局与空气质量形成机制研究
项目简介
本项目基于中国 20 个热门旅游城市的长期气象数据和空气质量数据，构建城市气候画像，分析城市气候格局、时空变化规律以及空气质量形成机制，并开发交互式可视化平台进行展示。
项目涵盖数据采集、数据清洗、特征工程、探索性数据分析、聚类分析、时空变化分析、极端天气形成机制研究以及机器学习解释分析等完整数据科学流程。
最终成果包括：
•	气候与空气质量数据库
•	多维度城市画像体系
•	空气质量形成机制分析
•	基于机器学习的AQI解释模型
•	在线交互式可视化平台

研究背景
随着旅游业快速发展和公众对宜居环境关注度不断提高，气候条件与空气质量已成为影响旅游目的地吸引力的重要因素。
不同城市在温度、湿度、降水、空气污染物浓度等方面存在显著差异，而这些差异背后又受到复杂气象过程和地理环境的共同影响。
本项目希望通过数据分析方法回答以下问题：
1.	中国热门旅游城市可以划分为哪些气候类型？
2.	不同城市的旅游舒适度存在怎样的差异？
3.	十年间城市气候发生了哪些变化？
4.	极端天气事件的空间分布特征如何？
5.	天气因素能否解释空气质量变化？

DS04 天气对空气质量形成机制解释
研究目标：
仅使用天气变量预测空气质量指标。
预测对象：
•	PM2.5
•	PM10
•	NO₂
•	SO₂
•	O₃
机器学习模型：
•	Random Forest Regressor
解释方法：
•	Feature Importance
•	SHAP Analysis
研究意义：
探索天气因素对空气污染物形成过程的影响机制，而非利用地理位置进行预测。
