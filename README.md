# 中国热门旅游城市气候格局与空气质量形成机制 - 静态网站

## 使用方法
1. 解压本文件夹。
2. 将 `index.html`、`css/`、`js/` 放到你的项目根目录：`D:\qq\数据可视化\weather_city_project\`
3. 保持图片目录结构不变：`data/figures/`
4. 双击 `index.html` 即可打开。

## GitHub Pages部署
1. 新建 GitHub 仓库。
2. 上传 `index.html`、`css/`、`js/`、`data/figures/`。
3. Settings → Pages → Deploy from a branch → main / root。
